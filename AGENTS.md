# AGENTS.md — semantic-release-monorepo

> Clearcover's fork of `semantic-release-monorepo`: a semantic-release plugin set that
> filters commits per package and namespaces git tags (`<pkg-name>-v<version>`) to enable
> independent versioning of packages in a monorepo.

## Quick start

```bash
# Install
yarn install

# Test — must pass before every PR
yarn test

# Format (auto-fixes .js files)
yarn format:all
```

> Note: `yarn format:all` runs `prettier --write` on `./**/*.js` only (not .ts/.tsx).
> It auto-fixes in place — it does not just check. Run before committing.
